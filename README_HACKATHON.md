# SmartExecutor — Arbitrage Scanner

**Build with CMC: API Hackathon 2026 — RWA Track**

## Что это

Мультибиржевой сканер арбитражных возможностей для крипто-активов, включая **токенизированное золото (XAUT)**.

## Что умеет

1. **Межбиржевой арбитраж** — сравнение цен одного актива на 4 биржах:
   - Binance
   - Bybit
   - OKX
   - Kraken

2. **Внутрибиржевой арбитраж** — сравнение спота и фьючерса на одной бирже (базис).

3. **RWA-данные** — через CoinMarketCap API:
   - Список эмитентов токенизированных активов.
   - Токены Tether Holdings (XAUT).
   - Цены, объёмы, капитализация.

4. **Учёт комиссий** — чистая прибыль с учётом taker-комиссий на обеих сторонах.

5. **Порог сигнала** — 0.5% (защита от ложных сигналов).

## Как это работает

Опрос всех источников (4 биржи)

Поиск min (где купить) и max (где продать)

Расчёт спреда

Вычет комиссий (0.2% на двух биржах)

Если чистая > 0.5% → сигнал


## Использование CoinMarketCap API

- `/v5/real-world-assets/issuers/list` — список эмитентов RWA
- `/v5/real-world-assets/issuers?issuer_id=...` — токены эмитента
- `/v3/cryptocurrency/quotes/latest?id=5176` — цена XAUT
- `/v3/cryptocurrency/listings/latest` — топ монет
