# Индикаторы

Справочник по индикаторам, используемым агентом.

---

## 1. Что такое индикатор

**Индикатор** — математический расчёт на основе **цены и объёма**. Помогает понять состояние рынка.

**Три типа:**
- **Трендовые** — показывают направление (MA).
- **Осцилляторы** — показывают перекупленность / перепроданность (RSI).
- **Волатильность** — показывают размах (ATR).

---

## 2. ATR (Average True Range)

**Что:** средний истинный диапазон. **Средний размах цены** за N свечей.

### Формула (упрощённо)

TR = max(high - low, |high - prev_close|, |low - prev_close|)
ATR = среднее TR за N периодов (обычно 14)


### Что показывает
- **Волатильность.** Чем выше ATR — тем больше движение.
- Не показывает **направление** — только **размах**.

### Как читать
- **Низкий ATR** — спокойный рынок.
- **Высокий ATR** — волатильный рынок.

### Использование у нас
- **TraderSense** — `volatility_level` по ATR / price.
- **InstitutionalCore** — для расчёта стопа (R-019).
- **LevelBuilder** — считает ATR при сборе данных.

### Пороги (для TraderSense)
- ATR/price < 0.5% → `neutral`.
- 0.5–2% → `trending`.
- 2–5% → `volatile`.
- > 5% → `storm`.

---

## 3. RSI (Relative Strength Index)

**Что:** индекс относительной силы. **Осциллятор 0–100.**

### Формула (упрощённо)

RSI = 100 - 100 / (1 + RS)
RS = средний рост / среднее падение за N периодов (обычно 14)


### Что показывает
- **Перекупленность** (RSI > 70).
- **Перепроданность** (RSI < 30).
- **Силу тренда.**

### Как читать
- RSI > 70 → возможен разворот вниз.
- RSI < 30 → возможен разворот вверх.
- **Дивергенция** — цены растут, RSI падает → слабость.

### Использование у нас
- **TrendAnalyzer** — определение фазы.
- **KnowledgeBase** — есть карточка «дивергенция RSI».
- Пока **не реализовано** в коде.

### Требует проверки
- ⚠️ Период RSI для наших таймфреймов.

## 4. MA (Moving Average)

**Что:** скользящая средняя. **Среднее цены за N свечей.**

### Виды
- **SMA** — простое среднее.
- **EMA** — экспоненциальное (сильнее реагирует на новые цены).

### Что показывает
- **Направление тренда.**
- **Поддержку / сопротивление.**

### Как читать
- Цена > MA → бычий сигнал.
- Цена < MA → медвежий сигнал.
- **Пересечение MA** — смена тренда.

### Популярные периоды
- MA-50, MA-200 — для **долгосрочного** тренда.
- MA-20 — для **среднесрочного**.
- MA-9 — для **краткосрочного**.

### Использование у нас
- **TrendAnalyzer** — определение направления.
- Пока **не реализовано** в коде.

### Требует проверки
- ⚠️ Какие периоды MA использовать.

## 5. Volume (Объём)

**Что:** количество монет, проданных за период.

### Что показывает
- **Силу движения.** Большой объём — сильное движение.
- **Подтверждение пробоя.** Пробой + объём = настоящий.
- **Слабость.** Пробой без объёма = ложный.

### Как читать
- Объём **выше среднего** → движение сильное.
- Объём **ниже среднего** → движение слабое.
- **Всплеск объёма** → что-то произошло.

### Использование у нас
- **LevelBuilder** — `volume_current`, `volume_average`, `volume_above_level`.
- **TraderSense** — `volume_weak` (объём < 70% среднего).
- **InstitutionalCore** — каскады ликвидаций (объём ×1.5).

---

## 6. Order Book (Стакан)

**Что:** список **активных ордеров** на покупку и продажу.

### Что показывает
- **Ликвидность** на разных уровнях.
- **Крупные заявки** — стены.
- **Спред** — разница bid/ask.

### Как читать
- **Толстый стакан** → высокая ликвидность.
- **Тонкий стакан** → низкая ликвидность.
- **Стена** → крупная заявка, цена может отскочить.

### Использование у нас
- **OKXConnector** — `get_orderbook` (есть метод).
- Пока **не используется** активно.
- **Планируется** для более точной оценки ликвидности (вместо `volume_above_level`).

### Требует проверки
- ⚠️ Как часто обновлять стакан.
- ⚠️ Как учитывать в решениях.
