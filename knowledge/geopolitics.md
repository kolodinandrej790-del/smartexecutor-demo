# Геополитика

Справочник по геополитическим факторам, влияющим на крипту.

---

## 1. Что такое геополитика для рынка

**Геополитика** — события в мире, влияющие на **глобальные рынки**:
- санкции;
- конфликты;
- политика центробанков;
- экономические блоки.

**Ключевое для нас:**
- Геополитика — **драйвер**, не «фон».
- Двигает **золото**, **нефть**, **доллар**.
- Через них — **крипту**.
- **XAUT** — главный индикатор (золото = risk-off).

---

## 2. Санкции (Sanctions)

**Что:** экономические ограничения против страны / компании.

### Влияние на крипту
- **Risk-off** → крипта падает на 3–10%.
- **Ускорение** использования крипты в обход санкций.
- **Страны под санкциями** — активнее используют BTC.

### Пример
- Санкции против России (2022) → BTC -8%, потом рост.
- Санкции против Ирана → рост использования BTC.

### Сигнал
- **Рынок:** SELL, осторожность.
- **XAUT:** BUY (золото = убежище).

### Тип в Event
- `geopolitics`, влияние `-2` до `-3`.

---

## 3. Конфликты (Conflicts)

**Что:** военные действия, политические кризисы.

### Влияние на крипту
- **Мгновенный risk-off.**
- **Золото** растёт (убежище).
- **BTC** — иногда растёт, иногда падает (зависит от контекста).
- **Нефть** растёт → инфляция → давление на всё.

### Пример
- Начало конфликта на Ближнем Востоке (2024) → BTC -5%, золото +3%.

### Сигнал
- **Risk-off** → SELL.
- **XAUT:** BUY.

### Тип в Event
- `geopolitics`, влияние `-3`.

---

## 4. Ставки ФРС (Fed Rates)

**Что:** изменение ключевой ставки Федеральной резервной системы США.

### Влияние на крипту
- **Повышение ставки** → деньги дорожают → крипта падает.
- **Понижение ставки** → деньги дешевеют → крипта растёт.
- **Ожидания** важнее **факта**: совпало / не совпало.

### Пример
- ФРС повысила ставку на 0.5% (2022) → BTC -10%.
- ФРС понизила ставку (2024) → BTC +5%.

### Календарь
- Заседания ФРС — **8 раз в год**.
- Объявления **в 19:00 UTC** (обычно).
- **FedWatch** показывает вероятности.

### Сигнал
- **Повышение** → SELL.
- **Понижение** → BUY.
- **Перед объявлением** — не входить.

### Тип в Event
- `macro`, влияние `-3` до `+3`.

---

## 5. Долг США (US Debt)

**Что:** государственный долг США. Сейчас — $36+ трлн.

### Влияние на крипту
- **Рост долга** → ослабление доллара → крипта растёт.
- **Риск дефолта** → risk-off → крипта падает **сначала**, потом растёт.
- **Долгосрочно** — бычий для BTC и золота.

### Пример
- Дефолт-2011 → золото +15%, BTC ещё не был.
- Дефолт-2023 (отложен) → крипта +5%.

### Сигнал
- **Долгосрочно:** BUY на BTC, XAUT.
- **Краткосрочно:** осторожность при новостях.

### Тип в Event
- `macro`, влияние `+1` до `+2` (долгосрочно).

---

## 6. БРИКС и дедолларизация

**Что:** блок стран (Бразилия, Россия, Индия, Китай, ЮАР + новые).
Цель — **уйти от доллара** в торговле.

### Влияние на крипту
- **Ослабление доллара** → крипта растёт.
- **Развитие** национальных систем (CBDC).
- **Китайский юань** — конкурент доллару.
- **Долгосрочно** — бычий для BTC и золота.

### Пример
- БРИКС объявил о планах дедолларизации (2024) → золото +3%.
- Развитие трансграничных платежей в юанях.

### Сигнал
- **Долгосрочно:** BUY на BTC, XAUT.
- **Следить** за встречами БРИКС.

### Тип в Event
- `macro`, влияние `+1` до `+2`.

### Проблема
- **Размыто.** Никто не берёт ответственность.
- **Реализация** — далеко.
- **Влияние** — на длинной дистанции.

## 7. Резервы стран (Reserves)

**Что:** золотовалютные резервы государств.

### Что происходит
- **Центробанки** покупают золото.
- **Отказываются** от долларов.
- **Замораживают** чужие резервы (пример: Россия, Венесуэла).

### Влияние на крипту
- **Рост золота** в резервах → золото дорожает → XAUT растёт.
- **Ослабление** доллара.
- **Недоверие** к системе → крипта как альтернатива.

### Пример
- 2024: центробанки купили рекордные 289 тонн золота.
- XAUT +8%.

### Сигнал
- **BUY** на XAUT при росте покупок.
- **Следить** за отчётами МВФ.

### Тип в Event
- `macro`, влияние `+1` до `+2`.

## 8. Золото как убежище

**Что:** золото — традиционный **защитный актив**.

### Когда растёт
- Войны, санкции.
- Инфляция.
- Кризисы.
- Ослабление доллара.

### Влияние на XAUT
- **XAUT следует** за золотом.
- В risk-off — **золото растёт**, XAUT тоже.
- В risk-on — **золото падает**, XAUT тоже.

### Пример
- 2024: обострение на Ближнем Востоке → золото +5%, XAUT +4%.

### Наш индикатор
- XAUT — **драйвер** для крипты.
- Рост XAUT → risk-off → осторожность с BTC/ETH.
- Падение XAUT → risk-on → можно покупать.

### Тип в Event
- `macro`, влияние `-1` до `+1` для крипты (обратная связь).

---

## 9. Нефть и энергия

**Что:** цены на нефть, газ.

### Влияние на крипту
- **Рост нефти** → инфляция → ФРС жёстче → крипта падает.
- **Падение нефти** → снижение инфляции → крипта растёт.
- **Энергия** — важна для майнеров BTC.

### Пример
- Нефть Brent +10% (2022) → BTC -5%.
- Нефть -20% (2023) → BTC +8%.

### Сигнал
- **Рост нефти** → осторожность.
- **Падение** → BUY.

### Тип в Event
- `macro`, влияние `-2` до `+2`.
