# Биржи

Справочник по биржам, с которыми работает SmartExecutor.

---

## 1. OKX

**Роль:** основная биржа. Здесь ведётся реальная торговля.
**Сайт:** okx.com
**Тип аккаунта:** субаккаунт SmartExecutor.

### Комиссии
- **Spot maker:** 0.08%.
- **Spot taker:** 0.10%.
- **Futures maker:** 0.02%.
- **Futures taker:** 0.05%.

### Доступные пары (интересующие)
- `BTC-USDT` — спот.
- `ETH-USDT` — спот.
- `XAUT-USDT` — спот.
- `PAXG-USDT` — ⚠️ требует проверки.

### Особенности API
- Формат символов: **дефис** (`XAUT-USDT`).
- Подпись: **HMAC-SHA256** + base64.
- Timestamp: ISO8601 с миллисекундами.
- SL/TP: через **`attachAlgoOrds`** (R-022).
- `td_mode`: `cash` (спот), `cross`, `isolated`.

### Ограничения
- Спот SELL требует наличия актива.
- Лимиты API: 20 запросов / 2 сек (публичные).
- Требуется passphrase при подписи.

## 2. Bybit

**Роль:** источник цен. Лидер по XAUT.
**Сайт:** bybit.com

### Комиссии
- **Spot maker:** 0.10%.
- **Spot taker:** 0.10%.
- **Futures maker:** 0.02%.
- **Futures taker:** 0.055%.

### Доступные пары (интересующие)
- `XAUTUSDT` — спот ✅, linear ✅.
- `PAXGUSDT` — спот ❌, linear ✅.
- `BTCUSDT` — спот ✅, linear ✅.
- `ETHUSDT` — спот ✅, linear ✅.

### Особенности API
- Формат символов: **без разделителя** (`XAUTUSDT`).
- Endpoint: `/v5/market/tickers`.
- Параметр `category`: `spot` | `linear`.
- Публичный доступ — **без ключей**.

### Ограничения
- PAXG на споте **нет** — только linear.
- Лимиты: ⚠️ требует проверки.

## 4. Kraken

**Роль:** источник цен. Старейшая биржа.
**Сайт:** kraken.com

### Комиссии
- **Spot maker:** 0.16%.
- **Spot taker:** 0.26%.
- ⚠️ Комиссии **выше**, чем у других.

### Доступные пары (интересующие)
- `XAUTUSD` — спот ✅.
- `PAXGUSD` — спот ✅.
- `XBTUSD` — спот ✅ (BTC).
- `ETHUSD` — спот ✅.

### Особенности API
- Формат символов: **без разделителя**, `USD` вместо `USDT` (`XAUTUSD`).
- **BTC = `XBT`** — важно!
- Endpoint: `/0/public/Ticker`.
- Публичный доступ — **без ключей**.

### Ограничения
- Комиссии **высокие** — для арбитража менее выгоден.
- Ответ — **вложенная структура** (`result[pair_key]`).

## 5. CoinMarketCap (не биржа)

**Роль:** источник данных. Агрегатор.
**Сайт:** coinmarketcap.com

### Что даёт
- Цены по 483 парам XAUT.
- RWA-данные (эмитенты, токены).
- Метаданные монет.
- Fear & Greed Index.

### Тарифы
- **Basic:** 15 000 кредитов/мес, 50 запросов/мин.
- **Startup:** 450 000 кредитов/мес, 600 запросов/мин (активирован по хакатону).
- **Growth+:** аналитические endpoints (market-pairs).

### Особенности API
- Endpoint: `pro-api.coinmarketcap.com`.
- Ключ: `X-CMC_PRO_API_KEY`.
- Формат ответа: **`data` — список или словарь** (различается по endpoint).
- В RWA: `data.issuers[]`.

### Ограничения
- `market-pairs` — **недоступен** даже на Startup (нужен Growth).
- Лимит `symbol` не уникален — фильтровать по `slug` или `id`.

## 7. Заметки для InfoSense

**Приоритет источников:**
1. **Primary** — анонсы OKX, Binance (листинги, делистинги).
2. **Secondary** — цены через публичные API.
3. **Контекст** — CMC (RWA, метаданные).

**Что важно отслеживать:**
- Новые листинги на OKX / Binance.
- Делистинги.
- Технические работы (паузы торгов).
- Изменения комиссий.

## 8. Заметки для ArbitrageScanner

**Какие биржи опрашивать:**
- ✅ Binance, Bybit, OKX, Kraken.

**Комиссии учитываются:**
- Taker × 2 = 0.20% (по умолчанию).
- Если maker — 0.16–0.20%.

**Порог сигнала:** 0.5%.

**Особенности:**
- Kraken — высокие комиссии, редко участвует в сигнале.
- Bybit — можно торговать XAUT и на spot, и на linear.
- Binance — надёжный источник цен.
